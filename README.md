### 🚀 Featured Projects

#### [FlowLens](https://github.com/nikhilgetitdone2027/FlowLens)
*High-Performance Deep Packet Inspection Engine in C++*
- Built a multi-threaded load-balancer and worker pipeline parsing PCAP streams under heavy traffic.
- Implemented concurrent 5-tuple flow tracking and dynamic TLS/HTTP protocol inspection with minimal lock contention.

#### [ProximaEngine](https://github.com/nikhilgetitdone2027/ProximaEngine)
*C++ Vector Database & Retrieval-Augmented Generation (RAG) Core*
- Engineered Approximate Nearest Neighbor (ANN) search from scratch using Hierarchical Navigable Small World (HNSW) graphs.
- Supports 768-dimensional embeddings and direct integration with local LLM runtimes (Ollama).

#### [QuickShow](https://github.com/nikhilgetitdone2027/QuickShow)
*Real-Time Ticket Booking Platform*
- Production-ready MERN application with race-condition mitigation for seat-locking concurrency.
- Integrated background event handling and Stripe payment workflows.
